Техническое задание v3.1
Программа для быстрого прослушивания и редактирования каталогов аудиофайлов
Платформа: Debian (Linux)
Язык интерфейса: английский
Стек: C++ / Qt (без Python)

1. Общие положения
1.1. Назначение
Программа предназначена для быстрого просмотра, прослушивания и простого редактирования каталогов аудиофайлов. Основной сценарий — навигация по файловой системе, визуальный анализ содержимого (волна/спектрограмма), прослушивание, установка меток и базовые операции редактирования несжатого аудио (WAV/AIFF).

1.2. Целевая платформа
Debian (актуальные стабильные версии).

Сборка и поставка в виде make файла в каталоге репозитория и .deb-пакета.
Каталог debian/ + debhelper, сборка через dpkg-buildpackage.
`dpkg-buildpackage -us -uc -b`
Дополнительно прописать в зависимости ffmpeg.

Зависимости: libsndfile1, ffmpeg (fallback-декодер), libtag1 (TagLib), Qt 6 (Core, Widgets, Multimedia).

1.3. Технологический стек и размещение данных
UI: Qt 6 Widgets.

Чтение/запись PCM и метаданных WAV/AIFF/FLAC: libsndfile.

Чтение тегов прочих форматов: TagLib.

Декодирование прочих форматов (mp3, ogg, m4a и т.п.) только для воспроизведения: QProcess + ffmpeg (fallback), результат — временный WAV, читаемый через libsndfile.

Воспроизведение: Qt Multimedia (QAudioSink) из декодированного PCM-буфера.

Нормализация: собственный код над PCM (ffmpeg не используется).

Хранилище настроек: ~/.config/<app>/config.json (статика) + SQLite (динамика).

Кэш превью: подкаталог каталога настроек приложения.

Undo-данные: каталог, задаваемый в настройках (по умолчанию — подкаталог каталога настроек).

1.4. Форматы
Редактируемые (чтение + запись PCM):

WAV (PCM)

AIFF

CAF (PCM) — опционально

Только чтение/воспроизведение:

FLAC

MP3, OGG/Vorbis, M4A/AAC и прочие, поддерживаемые ffmpeg

«Несжатые форматы» в контексте редактирования = WAV, AIFF, CAF (PCM).

2. Интерфейс
2.1. Общая структура окна
text
┌──────────────────────────────────────────────────────────┐
│ Верхняя панель: поиск, выбор колонок,                      │
│ режим превью таблицы (волна/спектр),                       │
│ обновление превью каталога, zoom, настройки                │
├───────────┬──────────────────────────────────────────────┤
│ Дерево    │  Таблица файлов выбранного каталога          │
│ каталогов │  (сортируемая, с перестановкой колонок)      │
├───────────┴──────────────────────────────────────────────┤
│ Панель действий над активным файлом:                     │
│ mute / normalize / delete selection / удалить все метки  │
├──────────────────────────────────────────────────────────┤
│ Панель плеера: prev | play/pause | stop | next | loop    │
│ ползунок громкости | режим отображения плеера             │
│ (волна/спектр) | zoom in/out                              │
├──────────────────────────────────────────────────────────┤
│ Область визуализации: волна/спектрограмма,               │
│ метки, выделение, курсор, зум                            │
└──────────────────────────────────────────────────────────┘
2.2. Верхняя панель
Поле поиска файла по имени.

Кнопка запуска поиска.

Кнопка выбора колонок (меню с галочками).

Переключатель режима превью в таблице файлов: волна / спектрограмма (независимо от режима плеера).

Кнопка принудительного обновления превью текущего каталога (сброс кэша превью каталога).

Кнопка zoom in / zoom out (дублирует горячие клавиши).

Кнопка вызова окна настроек.

2.3. Панель каталогов (слева)
Дерево файловой системы.

Выбор каталога инициирует фоновое сканирование для заполнения таблицы.

2.4. Таблица файлов (центр)
Колонки:

Имя файла

Превью содержимого (волна или спектрограмма; режим переключается в верхней панели)

Продолжительность

Sample Rate

Sample Type (отображение: Float32, Int24, Int16, UInt8 и т.п.)

Количество каналов

Размер файла

Комментарий (если присутствует в файле)

Date Create

Date Modified

Поведение:

Колонки можно включать/выключать через меню в верхней панели.

Порядок колонок меняется перетаскиванием (drag-and-drop влево/вправо).

Сортировка — только по одной колонке, по клику на заголовок (переключение возрастание/убывание). Индикатор сортировки — на заголовке.

Сортировка по колонкам «Превью» и «Комментарий» запрещена (индикатор сортировки на этих колонках неактивен).

Превью генерируются лениво; количество предзагружаемых файлов задаётся в настройках (по умолчанию 30).

Размер превью: 340 × 20 px при 72 ppi.

Битые/недоступные файлы выделяются красным цветом и пропускаются при сканировании (строка отображается, но без аудио-параметров/превью; действия над ней недоступны).

2.5. Панель действий над активным файлом
Mute.

Normalize (с полем целевого уровня в dBFS рядом).

Delete selection.

Удалить все метки текущего файла.

Переименовать файл.

Если выделение отсутствует — действия применяются ко всему файлу. При наличии выделения — только к выделенной области.
Действия редактирования доступны только для редактируемых форматов (WAV/AIFF/CAF).

2.6. Панель плеера
Кнопки: Prev, Play/Pause, Stop, Next, Loop.

Ползунок громкости (управляет усилением только внутри приложения, не системной громкостью).

Переключатель режима отображения плеера: волна / спектрограмма (независимо от режима превью таблицы).

Кнопки zoom in / zoom out.

Поведение:

Prev/Next — в пределах текущего каталога с учётом текущей сортировки. В конце списка — стоп.

Play — воспроизведение целиком или только выделенного фрагмента (если выделение есть).

Stop — остановка и возврат к точке, откуда начали Play.

Loop — при активном зацикливании и наличии выделения циклически воспроизводится только выделенный фрагмент; без выделения — весь файл.

2.7. Область визуализации (внизу центрального окна)
Отображает волну или спектрограмму файла (режим задаётся переключателем в панели плеера).

Ползунок-указатель текущей позиции, перемещается во время воспроизведения.

Указатель можно перемещать мышью и кнопками «влево»/«вправо».

Метки отображаются вверху области и пересекают изображение тонкой пунктирной линией.

Выделение отображается полупрозрачной заливкой с границами; края выделения можно тянуть за маркеры.

При сильном приближении (до уровня сэмплов) сэмплы отображаются точками/столбиками.

3. Работа с файлами и каталогами
3.1. Сканирование каталога
При переходе в каталог программа сканирует его в фоне для заполнения таблицы (имя, размер, даты, аудио-параметры, комментарий).

3.2. Переименование
Любой аудиофайл можно переименовать. При переименовании обновляется путь в БД меток и кэша превью.

3.3. Ошибки доступа и битые файлы
Битые/недоступные файлы выделяются красным цветом и пропускаются при сканировании (строка остаётся видимой, но без аудио-параметров и превью; действия над ней недоступны).

При отсутствии прав на запись операции редактирования/переименования блокируются с понятным сообщением.

4. Метки (Markers)
4.1. Создание
Ctrl + двойной клик по области аудиосодержимого — создать метку.

Alt+M — создать метку в текущей позиции курсора.

4.2. Выбор и редактирование
Одинарный клик по метке — сделать активной.

Двойной клик по метке — всплывающее окно с характеристиками:

имя (редактируемое);

время внутри файла;

кнопка удаления метки.

Перетаскивание метки мышью — изменение её положения.

4.3. Удаление
Delete — удалить активную метку.

Кнопка во всплывающем окне метки.

Кнопка «удалить все метки» на панели действий — для текущего файла.

Кнопка «удалить все метки» в окне настроек — очистка всей БД меток.

4.4. Хранение
Метки хранятся в БД приложения (SQLite) в каталоге настроек, не в аудиофайле.

Запись: путь к файлу, размер, mtime, JSON-массив меток.

Время метки хранится в сэмплах (для точности) + дублируется в секундах для отображения.

JSON метки: {"name": "...", "time_samples": N, "time_sec": T}.

4.5. Сканирование меток (в окне настроек)
Алгоритм:

Взять запись из БД.

Проверить наличие файла по пути.

Нет файла → удалить запись, перейти к следующей.

Проверить размер и mtime.

Не совпадают → удалить запись, перейти к следующей.

4.6. Метки и удаление фрагмента
Метки, попавшие в область удаления, удаляются.

При undo операции удаления метки восстанавливаются на исходных позициях.

Метки после точки удаления сдвигаются на длину удалённого фрагмента; при undo — возвращаются.

5. Выделение
5.1. Создание
ЛКМ в области аудиосодержимого + протяжка мышью → выделение.

Двойной клик в области файла между метками → выделяется фрагмент между этими метками.

5.2. Управление
Клик без протяжки — снимает выделение и ставит курсор.

Esc — снять выделение.

Края выделения можно тянуть за маркеры.

Выделение отображается полупрозрачной заливкой с границами.

6. Воспроизведение
Воспроизведение целиком или только выделенного фрагмента.

При активном зацикливании и наличии выделения циклически воспроизводится только выделение.

Stop возвращает к точке, откуда начали Play.

W — переход в начало файла.

Ползунок громкости управляет усилением только внутри приложения.

7. Масштабирование
Ctrl + колёсико мыши в области аудиосодержимого.

Ctrl + стрелка «вверх»/«вниз» при наличии активного файла.

Кнопки zoom in / zoom out в верхней панели и панели плеера.

Ctrl+0 — сброс масштаба (весь файл).

Диапазон: от «весь файл в секундах» до «отдельные сэмплы».

Центр масштабирования — позиция курсора мыши в момент начала масштабирования (если курсор у края — центр у края).

При приближении до уровня сэмплов — отображение сэмплов точками/столбиками.

Синхронная горизонтальная прокрутка (Shift+колесо или нижний скроллбар).

8. Редактирование (только несжатые форматы: WAV/AIFF/CAF)
8.1. Общее правило
Если выделение отсутствует — действие применяется ко всему файлу. При наличии выделения — только к выделенной области.

8.2. Mute
Замена сэмплов выделения (или всего файла) нулями.

8.3. Normalize (пиковая)
Найти максимум abs(sample) по области.

Коэффициент = target_peak / current_peak, где target_peak = 10^(dBFS/20).

Умножить все сэмплы области на коэффициент.

Целевой уровень задаётся в поле рядом с кнопкой нормализации (dBFS, например −1.0 dBFS).

Реализуется собственным кодом над PCM (ffmpeg не используется).

8.4. Delete selection
Удаление выделенного участка из файла.

Метки в области удаления удаляются; метки после — сдвигаются.

Операция обратима (undo/redo).

При отсутствии выделения действие недоступно (по умолчанию).

8.5. Undo / Redo
Ctrl+Z — undo, Ctrl+Shift+Z / Ctrl+Y — redo.

Стек undo с выгрузкой исходных сэмплов изменённых участков на диск (каталог задаётся в настройках; по умолчанию — подкаталог каталога настроек), в памяти — только метаданные.

Запись undo содержит: тип операции, диапазон (offset + length), исходные сэмплы (на диске), метаданные для redo, список удалённых/сдвинутых меток.

Глубина истории и лимит дискового пространства задаются в настройках (по умолчанию: 20 шагов, 2 ГБ). При превышении — удаляются самые старые записи.

История undo действует в пределах сессии; между сессиями не сохраняется.

9. Горячие клавиши
Горячие клавиши подлежат переназначению через окно настроек. Значения по умолчанию:

Клавиша	Действие
Ctrl+M	mute
Ctrl+N	normalize
P	prev
N	next
Space	start/stop или start/pause (по выбору в настройках)
W	в начало файла
Ctrl+Z	undo
Ctrl+Shift+Z / Ctrl+Y	redo
Ctrl+Up / Ctrl+Down	zoom in / zoom out
Ctrl+0	сброс масштаба
Alt+M	создать метку в позиции курсора
Ctrl + двойной клик	создать метку
Delete	удалить активную метку
Esc	снять выделение
← / →	перемещение указателя (когда фокус в области визуализации)
10. Настройки и хранилище
10.1. ~/.config/<app>/config.json (глобальные статические настройки)
Громкость, установленная последний раз.

Режим отображения превью в таблице файлов (волна / спектрограмма), выбранный последний раз.

Режим отображения плеера (волна / спектрограмма), выбранный последний раз.

Поведение Space: start/stop или start/pause.

Глубина undo-истории и лимит диска под undo.

Каталог для undo-данных.

Количество предзагружаемых превью (по умолчанию 30).

Набор и порядок колонок.

Переназначенные горячие клавиши (если отличаются от значений по умолчанию).

10.2. SQLite (динамические данные)
Метки по файлам.

Кэш превью (соответствие UUID ↔ аудиофайл, с полем format_version).

Последнее состояние: открытый каталог, выбранный файл, позиция в файле.

10.3. Кэш превью
Каталог — подкаталог каталога настроек приложения.

Файлы-картинки с именами UUIDv4.

Соответствие «картинка ↔ аудиофайл» — в SQLite.

Ключ: путь + размер + mtime.

Кнопка принудительного обновления превью текущего каталога — в верхней панели.

Кнопка удаления всех превью — в окне настроек.

10.4. Окно настроек
Кнопка «удалить все метки» (очистка БД меток).

Кнопка «сканировать метки» (алгоритм п. 4.5).

Кнопка «удалить все превью».

Параметры undo (глубина, лимит диска, каталог undo-данных).

Количество предзагружаемых превью.

Поведение Space.

Режим отображения превью в таблице по умолчанию.

Режим отображения плеера по умолчанию.

Редактор горячих клавиш (переназначение).

11. Метаданные
Комментарий: для WAV — чанк LIST/INFO/ICMT; для FLAC — Vorbis COMMENT/DESCRIPTION; для прочих — через TagLib (ID3 COMM, MP4 и т.д.). Отображается, если присутствует.

Sample Type: отображение в формате Float32, Int24, Int16, UInt8 и т.п.

Date Create / Date Modified: из файловой системы.

12. Нефункциональные требования
Сканирование каталога и генерация превью — в фоновых потоках, UI не блокируется.

Ленивая загрузка превью (количество — из настроек).

Корректная обработка битых/недоступных файлов: выделение красным цветом в таблице, пропуск при сканировании (без аудио-параметров и превью), действия над такими строками недоступны.

При отсутствии прав на запись — операции редактирования блокируются.

Поставка в виде .deb-пакета с указанием зависимостей.

13. Вне области ТЗ (для ясности)
Многодорожечное редактирование.

Обработка эффектов (кроме mute/normalize).

Экспорт в другие форматы.

Сетевые функции.

Локализация интерфейса (только английский).
